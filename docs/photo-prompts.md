# Photo prompts for The Interactive Digital Wardrobe

144 items still use the illustration. Each section below is one image: generate it, download it as **PNG with a transparent background**, keep the file name exactly as written, then upload it to the repository (root folder or `images/upload/`).

After uploading, `python3 tools/prepare_photos.py` checks and prepares the files and prints the lines to add to `PHOTOS` in `index.html`.

**Checklist for every image:** real transparent background (not a grey/white checkerboard) · whole item visible · colour as described · PNG, not JPG.

Already done: camel-coat, light-wide-leg-jeans, white-tshirt.
